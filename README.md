# 省赛控制台

STM32F407ZGT6 比赛固件与 Qt Quick 上位机。新协议仅用于本仓库固件和上位机，不能直接连接旧文本协议固件。

## 工程

- `firmware/`：完整两轮比赛、扫码、视觉、距离路线与圆弧、绕障路线、取放动作组、串口屏、HWT101；包含独立 Keil 工程及必要驱动。
- `upper_computer/`：Windows x64 / Android arm64 共用 Qt Quick 界面。
- `shared/`：C99/C++ 共用二进制帧定义及[协议说明](shared/protocol.md)。
- `tests/`：协议、CAN 邮箱、机构实际运行服务、Flash 和上位机控制器测试。

## 使用

Windows 解压 Release ZIP 后运行 `windows/shengsai_tuner.exe`。Android 安装 arm64 APK，最低 Android 9。首次蓝牙扫描时允许所需权限。

电脑 USB 串口直接连接；使用 HC-05 时先在 Windows 系统中配对，选择对应的出站 COM 串口。安卓直接扫描并连接 HC-05 经典蓝牙。HC-05 需预先配置为从机、115200、8N1；应用不会发送 AT 配置指令。USB 转串口和 HC-05 使用同一 UART5，互斥接入。

连接后先确认电机映射、方向、限位、急停与机构实际零点。界面的“确认安全与零点”只设置软件坐标，**不会自动回零**。云台手动调整、动作故障或停止导致坐标失效时，将机构实际恢复零点后再确认。

- 比赛：选择启停区，在与串口屏一致的地图中选两个障碍区域，再启动比赛或仅跑图。整块红框禁行；主控预检路线，无路时拒绝启动。尽量减少横移，空间允许时连续圆弧转弯。离线准备后，PC9 短按选启停区1、长按选启停区2。预置动作组保持独立。
- 圆环：先读取三组参数，再编辑水平位置及云台角度并固化；保存不驱动机构。
- 视觉：仅自动标定2号圆环，支持手动读写比例。自动标定结果先应用，需点击“保存到主控”才掉电保留。
- 手动：拖动舵机指令角度、微调5/6轴、按住前后点动。底盘松手、页面切换或失焦即请求停止，主控另有300ms点动指令期限和1s心跳保护。

明确启动的离线完整比赛不依赖上位机持续在线；手动控制和标定需要保持连接。急停在主控锁定，必须重新确认才能恢复。

串口屏确认障碍区域，或上位机下发“离线按钮启动准备”“开始比赛”“仅跑图”时，主控准备夹爪闭合（已配置角度）、转盘26°、云台53°，等待三路舵机指令结束后才启动路线；不操作5/6号轴，不重新建立失效的机构坐标。仅在地图中点选不会触发运动。两个入口共用RAM选区，重启后重新选择，忙碌或急停时拒绝下发。新上位机需配套HELLO路线修订1固件，旧4字节路线请求被拒绝。

## 构建与验证

Qt 6.11.1 / C++17。Windows 安装 Qt Quick、Quick Controls 2、SerialPort、Test；Android 另需 Qt Bluetooth。

```powershell
./tools/build-windows.ps1
```

也可用自己的 Qt 路径运行标准 CMake 配置、构建及 CTest。具体 SDK、NDK、签名与打包步骤见[构建说明](docs/build.md)。

固件使用 Keil MDK / ARMCC 5.06 update 7，打开 `firmware/MecanumJog.uvprojx`。所有驱动路径在本仓库内，无需旧参考工程。

上电前两机构轴须实际在零点。当前仍停用云台、转盘的上电归位，三个舵机通道上电均不启用 PWM，后续明确的手动、障碍位置下发或比赛动作指令才启用对应通道。软件初值不是实际角度反馈；完整比赛的初始姿态检查仍保留，转盘26°及夹爪状态仍需预先准备。障碍位置下发后云台使用53°行驶姿态，到取料区后转到260°观察。尚未确认机械映射及安全条件时，不要进行联动。

## 云台重新安装后的角度

2026-10-22 视觉观察角度由 272° 改为 260°，同一云台的既有目标统一减去 12°，夹爪、转盘、5/6 号轴坐标和运动速度不变。

| 姿态 | 原角度 | 当前角度 |
| --- | --- | --- |
| 视觉观察 | 272° | 260° |
| 行驶收拢 | 65° | 53° |
| 托盘取放方向 | 132° | 120° |
| 下方夹取 | 268° | 256° |
| 左上 / 右上夹取 | 289.3° / 250.4° | 277.3° / 238.4° |
| 默认 1 / 2 / 3 号圆环 | 307.8° / 263.7° / 230° | 295.8° / 251.7° / 218° |

以上角度均已直接修改为数值，运行时不套用安装偏移公式。Flash 两种已有记录格式均原样读取，上位机手动输入和滑块也直接使用绝对指令角度。若主控仍保存重新安装前的旧角度，需在上位机先读取，再录入新的三组圆环角度并固化；仅更新固件不会覆盖已有 Flash 参数。未保存过参数时使用表中的新默认值。

## 固化参数

| 地址 | 内容 |
| --- | --- |
| `0x08000000–0x0807FFFF` | 固件程序区 |
| 扇区8 `0x08080000` | 2号圆环视觉比例 |
| 扇区9 `0x080A0000` | 1/2/3号圆环落点 |
| 扇区10 `0x080C0000` | 原有夹爪角度 |
| 扇区11 `0x080E0000` | 原有障碍位置 |

比例保存采用追加记录、校验和最后写入的完整标记；重复值不重复写。扇区写满时拒绝继续保存，不自动擦掉上一有效比例。整片擦除会清除固化参数。
