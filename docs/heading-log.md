# 行驶角度记录

正式比赛和自动跑图时，主控每500ms将角度样本写入现有任务日志；路段或控制阶段变化、到站时立即补记。记录覆盖直行、原地转向和圆弧，不改变运动控制参数，不在采样时发送串口日志，离线比赛也可记录。

跑完后连接上位机，打开“日志”，点击“读取上次任务日志”，查找以`YAW`开头的行。例如：

```text
YAW ms=12340 step=6 seg=8 tpl=17 phase=D target=17900 actual=17850 error=50 age=10
```

- `ms`：开机以来的毫秒数；`age`：该IMU样本的年龄，单位ms。
- `step`：任务阶段索引；`seg`：当前路线段索引，均从0开始。
- `tpl`：固定路线模板ID；`17`为RC-1中间路线，非固定模板路线为0。
- `phase`：`D`直行控制、`T`原地转向、`C`圆弧、`A`到站。
- `target`、`actual`、`error`：目标角度、IMU实际角度、目标减实际的最短角度差，单位均为0.01°。例中为179.00°、178.50°、误差+0.50°。角度归一化到±180°，跨过边界时按最短角度差计算。

日志使用现有32KiB内存缓冲，满后按整行覆盖最早记录；上位机会提示前部已覆盖。新比赛/跑图启动会清空上次任务日志，断电不保留。请在再次启动任务或断电前读取。记录不能测量车体横向位置，仍需人工测量左漂距离。
