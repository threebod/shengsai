# 行驶角度记录

正式比赛和自动跑图时，主控每500ms将角度样本写入现有任务日志；路段或控制阶段变化、到站时立即补记。记录覆盖直行、原地转向和圆弧，不改变运动控制参数，不在采样时发送串口日志，离线比赛也可记录。

跑完后连接上位机，打开“日志”，点击“读取上次任务日志”，查找以`YAW`开头的行。例如：

```text
YAW ms=12340 step=6 seg=8 tpl=17 phase=D target=17900 actual=17850 error=50 age=10
```

- `ms`：开机以来的毫秒数；`age`：该IMU样本的年龄，单位ms。
- `step`：任务阶段索引；`seg`：当前路线段索引，均从0开始。
- `tpl`：固定路线模板ID；`17`为RC-1中间路线，非固定模板路线为0。
- `phase`：`D`直行控制、`T`原地转向、`C`圆弧、`A`到站。
- `target`、`actual`、`error`：目标角度、IMU实际角度、目标减实际的最短角度差，单位均为0.01°。例中为179.00°、178.50°、误差+0.50°。角度归一化到±180°，跨过边界时按最短角度差计算。

日志使用现有32KiB内存缓冲，满后按整行覆盖最早记录；上位机会提示前部已覆盖。新比赛/跑图启动会清空上次任务日志，断电不保留。请在再次启动任务或断电前读取。记录不能测量车体横向位置，仍需人工测量左漂距离。

## 加工区与暂存区角度

正式比赛在两轮加工区和暂存区的四个节点额外写入RAM任务日志，不增加UART实时输出：

`STATION ms=1010 step=9 area=TEMP stage=ARRIVE target=17900 actual=-17900 error=-200 age=10 vision=0`

- `area=COARSE/TEMP`：加工区/暂存区；`step=7/14`为两轮加工区，`9/16`为两轮暂存区。
- `stage=ARRIVE/ALIGNED/PLACE/DONE`：完成到站航向校正后、视觉对齐结束、开始放置、整组放置完成。
- `target/actual/error`单位0.01°，分别为路线目标航向、IMU角度、最短角度误差；`age`为样本年龄ms。
- `vision=5`为视觉已对齐，`12`为达到修正上限；ALIGNED节点也包含达到修正上限后继续放置的情形，须按此字段区分，不能仅凭节点名称认定视觉已对准。

通过“日志→读取上次任务日志”保存，下一次任务开始或断电前读取。对比同一站四条记录，可判断到站残差、视觉微移后的转角及机构放置期间的底盘角度变化。IMU角度不能单独判断云台标定、夹爪偏心、物料倾斜或圆环实际中心偏差。

## 对齐像素偏差

任务日志新增`PIX`行：`u/v`为识别中心，`au/av`为目标锚点，`du=u-au`、`dv=v-av`，单位均为320×240协议图像像素，正值分别向右、向下。`step`沿用任务索引，`mode/selector/target/token`标识视觉会话；普通响应`age`为主控接收后的时间，连续跟踪还包含相机报告年龄与协议传输补偿。

普通对齐有效反馈记`phase=OBS`，确认对齐记`ALIGNED`；连续跟踪记`TRACK`（同会话最多每100ms一次），结束的范围内样本记`IN_RANGE`并绕过限频。IN_RANGE对二层物料只表示该轮跟踪结束，之后仍走原稳定、复核及修正上限流程。仅记录通过现有校验的真实测量，不记录重复、错误会话或失效跟踪帧，也不从运动距离估算像素。二层达到修正上限后若没有再采图，最后的PIX是此前测量，不是最后一次移动后的实测残差。

像素记录只写RAM任务日志，跑完通过上位机读取；与STATION角度行配合分析。沿用32KiB整行覆盖机制，新任务或断电前及时读取。实体PC9长按选启停区2的门槛由1000ms缩短为500ms，30ms消抖和短按选启停区1不变。
