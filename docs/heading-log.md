# 行驶角度记录

正式比赛和自动跑图时，主控每500ms将角度样本写入现有任务日志；路段或控制阶段变化、到站时立即补记。记录覆盖直行、原地转向和圆弧，不改变运动控制参数，不在采样时发送串口日志，离线比赛也可记录。

跑完后连接上位机，打开“日志”，点击“读取上次任务日志”，查找以`YAW`开头的行。例如：

```text
YAW ms=12340 step=6 seg=8 tpl=17 phase=D target=17900 actual=17850 error=50 age=10
```

- `ms`：开机以来的毫秒数；`age`：该IMU样本的年龄，单位ms。
- `step`：任务阶段索引；`seg`：当前路线段索引，均从0开始。
- `tpl`：固定路线模板ID；`17`为RC-1中间路线，非固定模板路线为0。
- `phase`：`D`直行控制、`T`原地转向、`C`圆弧、`A`到站。
- `target`、`actual`、`error`：目标角度、IMU实际角度、目标减实际的最短角度差，单位均为0.01°。例中为179.00°、178.50°、误差+0.50°。角度归一化到±180°，跨过边界时按最短角度差计算。

日志使用现有32KiB内存缓冲，满后按整行覆盖最早记录；上位机会提示前部已覆盖。新比赛/跑图启动会清空上次任务日志，断电不保留。请在再次启动任务或断电前读取。记录不能测量车体横向位置，仍需人工测量左漂距离。

## 独立1680mm直行测试

上位机“手动”页的“1680mm直行测试”卡片提供“直行1680mm并记录角度”按钮。从当前停车位置沿当前车头方向前进，固定240RPM巡航上限，复用正式直线的加减速、前进比例及航向PID，不先转向，不执行机构或舵机动作，也不自动返回。此测试保留当前控制作为基准，未增加实际航向的平移补偿或修改PID参数。

先对齐地面参考线，测量车体同一位置到参考线的起始距离，运行测试后测量终点距离并注明向左或向右偏移。结束后立即通过“日志→读取上次任务日志”保存本次日志，再开始下一次。每次成功启动会清空上次日志；断电丢失。日志开头标记`STRAIGHT_TEST mm=1680 rpm=240`，正常结束标记`result=estimated_complete`，停止、故障或会话变更标记`result=aborted`。完成表示按指令估算的行程结束，不是地面实测到位。

测试以起步时IMU角度为目标，使用100ms的`PID`与500ms的`YAW`记录，末端补记`YAW phase=A`。独立测试的模板、子步均为0，与RC-1模板17区分。`analyze_heading_pid`可以直接解析并绘制此日志，`samples.csv`保留全部样本；`centre-spans.csv`只统计RC-1，因此独立测试时为空。现有`simulate_heading_pid`仍只接受RC-1两段数据，不能将独立测试伪装为RC-1进行模型验证。

测试期间可点击“停止直行测试”；切页、窗口失焦、主动断连及主控心跳超时会停止，急停、IMU/CAN故障保护照常生效。测试需要安全确认，不要求取放机构坐标有效，也不会触发机构归位。

## 直行PID采集与MATLAB分析

普通直行控制每100ms额外记录一行`PID`，包括实际采用的PID增益、目标/IMU角度、积分和滤波角速度、原始PID输出、速度缩放比例，以及经过轮速修调和限幅后的最终四轮指令混合量。原`YAW`角度日志继续每500ms记录转向、圆弧和到点。采集写入RAM，不增加周期串口发送，不修改PID增益。

`PIDCFG`记录每段使用的增益及输出/积分上限，带`_m`的量除以1000。`PID`后面的19列依次为：

```text
开机ms,IMU采样ms,连续段编号,任务阶段,路线段,离站子步,模板ID,目标角度,IMU角度,前进指令×4,右移指令×4,偏航指令×4,上一采样间隔的平均偏航指令×4,原始PID输出×100,积分×1000,滤波角速度×100,速度缩放×1000,本次控制间隔ms,偏航极性
```

角度单位0.01°；滤波角速度单位0.01°/s。轮速混合量是RPM指令，不是编码器实测速度。平均偏航指令按上一批已发送命令及其持续时间加权，不能把当前刚发出的命令当作上一间隔的输入。路段/子步变化或记录间断超过250ms会开始新的连续段，避免把工位作业时间混入动态响应。圆弧及圆弧出口的特殊控制不混入此直行PID数据。

先更新主控固件，沿相同方向、相同转速和载荷重复采集中间长直线。每次在该段结束后及时停止并读取任务日志，复制保存为UTF-8文本；记录加密后32KiB缓冲仅保留最近一段时间，不要等整场比赛完成才读取。每次另记实测横向偏移和行驶距离。取料动作、急停、机构零点等硬件操作仍按实车操作要求完成，本工具不会启动小车或写入参数。

在MATLAB中执行：

```matlab
addpath('E:/Download/project/gongchuang/shengsai/tools');
result = analyze_heading_pid('E:/你的日志目录/run1.txt');
```

输出位于`build/heading-pid/`：`samples.csv`为解码和单位换算后的完整数据，`centre-spans.csv`统计RC-1最后长直线（模板17、子步2）的角度误差，`recording.png`绘制角度、误差、原始/最终纠偏指令及平移转速指令。脚本还根据日志中的增益、积分和滤波角速度重建原始PID输出，帮助检查单位和记录是否一致；这是控制器输出核对，不能当作车辆闭环仿真。

拿到至少两条完整中间长直线日志后，可运行模型验证和候选参数试算：

```matlab
result = simulate_heading_pid('E:/你的日志目录/run1.txt');
```

脚本从同一文件中提取RC-1子步2的连续段，用第一段拟合、第二段验证，不能用验证段重新拟合参数。模型形式为100ms离散航向增量模型，检查0～400ms的输入延迟；只按训练误差选取稳定、偏航增益为正的模型。候选PID沿用原0.3°死区、积分防饱和、12RPM输出上限、速度缩放及整数指令，按20ms更新控制、100ms保持IMU样本。采样间的驱动响应和速度扰动由该近似模型表示。

输出`model-delays.csv`、`exploratory-candidates.csv`、`model-summary.json`及`model-validation.png`。分析门槛为验证拟合度至少70%、验证RMSE不超过0.3°、原参数闭环复现RMSE不超过0.3°，且包含纠偏输入的模型须比仅含速度项的对照模型降低至少20%验证RMSE。这些是筛选仿真模型的条件，不是小车运行故障阈值。

任一门槛失败时，`model_accepted=false`，`recommended_pid`为空，候选表仅保留试算结果。脚本不修改或下发固件参数。解析器及模型的合成自检数据只用于验证读取、单位、已知模型恢复和拒绝条件，不代表真实车辆响应。
