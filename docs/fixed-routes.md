# 完整固定路线模板

2026-10-26起，正式流程仅从 `firmware/route_candidates.h` 的完整模板目录中选择。地图折点、原始距离、出发/结束朝向、圆弧类型均固定；选区只用于按顺序判断整条模板是否通过，不能改变模板中的任何动作。删除运行时网格搜索、临时圆弧选择、隐式进站朝向替换及标定不兼容时取消圆弧的行为。

共42份完整模板，组成9个有序候选组；扫码→原料除首选上移860/855mm、左移870/900mm分别调校外，共用其余4份模板。两轮及两个启停区的三组站间路线共用同一目录。编号中的 `B` 表示明确列出的备用模板，与原路线有不同编号。新增备用通道来自原有可行绕行的固定结果，不在比赛运行时生成。
