# T-mini Plus 雷达预览

本功能使用 STM32F407 接收雷达，复用已有 UART5 USB/HC-05 链路将点云传给 Windows/Android 上位机。不需要 Linux 或 ROS。雷达页用于扫描调试，不驱动底盘、不自动识别障碍区域或启动绕行。

## 接线与首次使用

| 雷达端 | 主控端 |
| --- | --- |
| TX | PA10 / USART1_RX |
| RX | PA9 / USART1_TX |
| GND | 主控及雷达电源共地 |
| VCC | 稳定的5V电源，按厂家建议提供1A供电能力 |

雷达通信为3.3V UART、230400、8N1、无流控；供电5V不能误接到3.3V。按端子定义核对，勿按线色猜接线。正点原子M144Z-M4板须拔下JP3连接CH340和USART1的1—2、3—4跳线帽，连接STM32侧PA10/PA9，不接CH340侧TXD/RXD。其他板卡按原理图确认引出和占用。

1. 更新本次固件及上位机，接好雷达；保持底盘停止。
2. 在上位机原有“连接”窗口接入主控，进入新增“雷达”页。
3. 点击“开始扫描”。主控确认只表示已发送启动命令，收到完整点云后才显示扫描结果；无需确认机构零点。
4. 选择显示半径，移动真实物体核对角度、距离和点云变化。0°向上、90°向右，表示雷达原始角度，尚未标定为车头方向。
5. 鼠标悬停或点击点查看距离、光强及干扰标记。默认保留干扰点并显示红色；其他点按光强从蓝到黄着色。黑色物料不按低光强自动删除。
6. “隐藏干扰标记点”和显示半径只改变本页显示，不改主控检测规则或雷达设置。
7. 用“停止扫描”停止雷达，保留最后一圈并标为历史。全局停止/急停、主控会话变更或心跳超时也停止本预览。没有自动恢复或重发扫描启动。

雷达仅在显式请求后启动；上电不自动发扫描命令。该预览不作为任何运动的防撞依据。扫描实际频率与上位机预览频率分开显示；连续有效扫描每秒选取一圈传输，保留该圈全部采样，不做角度抽点。每圈上限1024点；坏包、接收溢出或超限使对应圈无效，恢复到新的有效圈后再传。

## 接收与传输

USART1 RXNE中断只收字节进入4096字节环形缓冲，主循环每轮最多解析512字节。雷达命令通过独立TXE字节队列发送，不阻塞等待串口。解析包含起始/结束角、跨0°插值、1点数据包、3字节采样及厂家双字节异或校验；启动应答描述符、零位包前的CT CRC字节在查找包头时跳过。未解码CT健康信息，不将其当作正常健康状态。

USART5仍为115200；点云作为低优先级二进制事件，每20ms最多一包，仅在没有待发送应答且发送队列基本空闲时入队，并保留原有应答/完成事件空间。正常6Hz扫描每圈约667点，预览约占4.2KB/s；拥堵时降低预览更新率，不阻塞控制处理。等待传输超过2秒的快照丢弃。

主控保留接收中的一圈及一份只读发送快照。上位机检查预览token、圈号、总点数、连续偏移和有效角度，收齐后一次替换画面，避免混合不同圈。扫描年龄包含主控快照等待及分包发送时间；不含未测量的蓝牙缓存/传输延迟。2.5秒内没有新鲜扫描时淡化历史点并提示；启动后3秒仍未收到完整圈则提示检查供电、接线和跳线帽。
