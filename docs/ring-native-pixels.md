# 圆环实际像素与首次采样等待

2026-11-01：圆环圆心、ROI、锚点、直径和对齐容差统一使用640×480实际像素，默认锚点(320,240)。连续三帧横纵偏差各0～+1实际像素才结束跟踪；不再先除以2并取整。15RPM轮速上限、10ms控制周期、350ms新鲜度、1000ms跟踪首帧期限及各项故障保护保持原值。原料与暂存物料仍使用原320×240坐标，二层物料改用独立标定视图。

主控与相机v1.0.25需配套更新：圆环视觉帧版本2，物料版本1，长度和CRC不变，版本不匹配拒收。上位机自动标定及手动比例均使用mm/实际像素；旧Flash比例记录只在加载时按新单位读取，不写Flash，新保存记录版本为0x56534302。默认比例0.556/0.572，旧比例减半后按0.001mm四舍五入。标定矩阵仍用于把像素偏差转为物理运动量。

首次采样耗时来自以下步骤，本次未缩短这些等待：

1. 到站后等观察机构反馈及云台完成；若已提前展开完成则不重复准备。
2. 相机首次调用数字算法时导入模块并创建模板缓存，此后复用缓存。
3. 每次新采样请求丢弃2帧，然后检测圆环及数字2。
4. 至少3帧、至少180ms，窗口内两轴波动各不超过4实际像素才返回稳定结果。漏检或超出波动范围会重置窗口。
5. 约1000ms仍未确认则返回无效，主控再请求；未收到响应的普通请求期限为1800ms。此处与跟踪阶段1000ms首帧期限不同。
6. 9600波特率、30字节、8N1时，每个方向的帧传输约31.25ms；采图、检测及界面显示另计。

不能仅凭180ms判定首次请求总耗时。相机VISION RING日志中，elapsed_ms表示请求经过时间，detect_ms为累计检测耗时，frames/hits为检测与命中数，window/window_ms/span为当前稳定窗口；这些值可以区分算法慢、反复漏检与窗口不稳定。日志不能覆盖主控发请求前的机构准备时间。
