## 取料双轴动作反馈超时（2026-10-22）

用户日志已进入`ROUTE RAWPICK state=PICK`，首个动作`MECH RUN h=549 l=530 t=2773`随后报`ERR MECH: feedback timeout`。定位到5/6轴共享状态/位置查询开关：两轴轮流被选中时，查询类型也同时翻转，导致一轴始终只查状态、另一轴始终只查实际位置，无法同时满足两轴到位和到位后新位置反馈的条件。改为每轴独立保存查询阶段，在运动准备及下发时分别重置；不延长超时、不绕过目标或到位校验。超时仍先停止并使坐标失效，再逐轴输出`AXIS TIMEOUT`，包含准备阶段、基准读取、目标匹配、到位、新位置反馈标志及耗时。
