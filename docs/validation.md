旧CTest唯一失败项`test_task12_host_static`需要工作区原本缺失的`yyb_stm32/host_protocol/host_uart3.h`。旧工程的源码和既有未提交修改保持原样；没有为绕过该项而改变旧工程。

## 尚需硬件验收

没有烧录或发送实机运动指令。以下必须由实车联调补齐：

1. 映射、方向、机械限位和急停，机构实际上电零点及云台/转盘启动净空。
2. 5/6轴低速短行程、长行程、双轴、带负载重复往返；对照日志里的输入目标、编码器位置、到位状态及外部测量。
3. CAN断线、驱动禁用/堵转、急停、蓝牙中断与窗口切换时的真实停止行为。
4. 三组圆环保存后实际掉电恢复；2号视觉比例应用、保存、掉电及离线启动使用。
5. Android9+真实手机权限拒绝、HC-05配对/扫描/重连、后台切换和触控拖动。
6. 两种启停区、障碍路线、两轮任务及全动作组在实车上的完整验证。

只有硬件验证后才能判断剩余偏差是否来自驱动跟随、传动打滑、零点或其他原因。本版消除了可见的按时间提前截断逻辑，不能将所有原有偏差归因于遗漏脉冲。

## 发布后的手机布局修正（2026-10-21）

针对手机截图中状态栏压住标题、手势条压住底部导航的问题，自定义顶部栏和底部栏改为读取窗口 `SafeArea`；正文保留 Qt 默认安全区域布局。手机卡片内边距和间距收紧，按钮保持 44 像素逻辑高度；下拉箭头改为绘制，避免系统字体缺字。连接、安全确认和日志弹窗限制在安全区域内，长内容滚动显示。

Windows 构建及完整 CTest 13/13 通过。新增 `layout` 测试直接加载生产 QML，覆盖 320×640、360×800、430×932、740×360、1280×860 五组逻辑尺寸，模拟状态栏、手势条、三键导航及横屏侧边开孔；检查四页固定栏、正文、交互控件横向范围、弹窗边界和运行中边距变化，无 QML 绑定警告。Android arm64 原生目标编译通过，未生成或发布新 APK。

[手机安全区域布局截图](design/mobile-safe-area.png)与[横屏布局截图](design/landscape-safe-area.png)来自 Windows 上运行的实际 QML，注入安全边距以模拟手机，空白区域为系统栏预留位置；并非手机实机截图。仍需在原截图对应手机验证状态栏、动态岛、手势导航、旋转及软键盘弹出后的效果。已发布的 `v0.1.0-preview.1` 安装包不包含此次修改。

## 暂停上电舵机归位（2026-10-21）

移除 `main()` 启动阶段云台 65° 和转盘 26° 的两条目标指令，上电三个舵机通道均不启用 PWM；启动日志改为 `servo_pwm=off`。保留后续手动、按钮启动和动作组中的指令，以及比赛初始姿态检查。首次比赛前需手动建立所需姿态，软件中的角度初值不代表真实反馈。

Keil 完整重建通过，0 错误、2 条已有第三方警告，日志为本地 `firmware/build-servo-startup.log`；Code81812、RO-data4356、RW-data824、ZI-data17448 字节。完整 CTest 13/13 通过。未烧录或进行实机上电验证，未重新打包或发布。
