# 省赛控制台 v0.1.0-preview.2

Android arm64 上位机更新，最低支持 Android 9。APK 沿用 preview.1 签名，版本号递增为 2，可覆盖安装旧版本。

- 修正顶部标题与状态栏重叠、底部导航压住手势条的问题，按系统安全区域避让；手机卡片间距收紧，保留按钮触摸高度。
- 连接、安全确认和日志弹窗适配安全区域及窄屏，下拉箭头改为绘制，避免字体缺字。
- 修正 Android 构建脚本，直接生成 APK；补充编译、签名、校验与安装步骤。
- 源码中的固件暂时停用云台 65°、转盘 26° 的上电归位，后续手动与比赛动作保留。完整比赛的初始姿态检查仍有效，首次比赛前需手动建立对应姿态。此固件修改需另行编译烧录，安装 APK 不会更新主控固件。

本次附件仅更新 Android 包，Windows 安装包仍可使用 preview.1。本仓库新上位机须配套二进制协议固件，不兼容旧文本协议。

验证：完整 CTest 13/13 通过；Android Release 构建、签名与 16KB 对齐验证通过，包内应用库与当前编译产物一致；固件 Keil 完整重建 0 错误、2 条已有第三方警告。布局截图是在 Windows 运行实际 QML 并注入手机安全边距的仿真图，不是安卓实机截图。

尚未完成手机安装、真实状态栏/手势条与蓝牙联调、固件烧录及实车验收，因此保留为预发布版本。实机运行前确认映射、方向、机械限位、实际零点和急停。

附件提供 APK、SHA256SUMS.txt、验证记录和布局截图。详见[打包说明](https://github.com/threebod/shengsai/blob/v0.1.0-preview.2/docs/build.md)与[验证记录](https://github.com/threebod/shengsai/blob/v0.1.0-preview.2/docs/validation.md)。
