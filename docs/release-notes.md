# 省赛控制台 v0.1.0-preview.1

首个预发布版本，包含独立STM32F407比赛固件和Qt Quick上位机。

- Windows x64：解压ZIP，运行`windows/shengsai_tuner.exe`，支持USB串口及Windows配对HC-05后的出站COM串口。
- Android arm64：安装APK，最低Android9，支持HC-05经典蓝牙扫描和连接；允许所需蓝牙权限。
- 四页卡片界面：比赛、圆环、视觉、手动。支持三组圆环落点固化、2号圆环自动标定及比例读写和掉电保存、舵机滑块、5/6轴微调和前后点动。
- 新固件改用带CRC、序号和应答的二进制协议；5/6轴改为目标验证和到位反馈推进，时间只作超时保护。

必须使用本仓库新固件，不能直接连接旧文本协议版本。固件工程和摄像头程序见仓库`firmware/`。Flash扇区8新增视觉比例，9/10/11保留原有参数，整片擦除会清除保存值。

软件与构建验证记录、界面截图见[验证记录](https://github.com/threebod/shengsai/blob/main/docs/validation.md)和[设计目录](https://github.com/threebod/shengsai/tree/main/docs/design)。原上位机CTest有一项因旧参考文件缺失失败，详见记录。

**未完成实车及安卓实机联调**：尚未烧录、验证真实掉电保持、机构往返位置精度、机械限位和完整比赛。修复了可识别的提前截断路径，不能据此断言所有位置偏差均由遗漏脉冲导致或已全部消除。首次运行前确认电机映射、方向、限位、急停，并将两机构轴实际放到零点。

下载文件旁提供SHA256校验。APK使用固定预发布签名，后续版本可沿用同一签名更新。
