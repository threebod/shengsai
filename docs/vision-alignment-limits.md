# 视觉对齐与比赛中止条件

## 圆环累计行程限制取消（2026-10-30）

按用户要求，圆环连续跟踪不再因初始视觉偏差对应的累计移动距离耗尽而返回 `TRACK_BUDGET`，也不再因剩余距离不足而减速、取整为零后结束。初始距离为零时仍等待视觉首帧，不将零距离当成已对齐。此前已取消的圆环总时长限制 `TRACK_DEADLINE` 继续保持取消。

圆环保持单次会话、每轮最高15RPM（包括修调和航向纠偏）、10ms控制周期。连续两帧新鲜目标偏差均在横纵各±1协议像素内才完成；未达到条件时持续调整，丢帧时停车等待同会话有效帧。二层物料的行程、时长以及最多两轮规则保持原值；取料区仍走独立布局微移流程。

## 仍可能中止比赛的条件

| 环节 | 条件 | 处理或日志 |
| --- | --- | --- |
| 连续跟踪首帧 | START后1000ms内没有匹配、新鲜、有效的跟踪结果 | `TRACK_ACK_TIMEOUT`，中止 |
| 连续跟踪目标 | 匹配会话的新鲜结果报告无效目标、质量不达标、超出ROI或物料身份错误 | `TRACK_TARGET_INVALID`，中止；重复、旧会话和过期帧仅忽略 |
| 相机协议或标定 | 不支持跟踪、标定无效、映射结果非法、运动比例非法或启动条件不满足 | `CAMERA_TRACKING_UNSUPPORTED`、`TRACK_CALIBRATION_INVALID`、`TRACK_SCALE_INVALID`或启动失败，中止 |
| 停车识别/取料布局通信 | 普通请求等待1800ms；布局每个新请求首帧1000ms，收到匹配响应后1800ms无响应；连续3次缺失 | `CAMERA_TIMEOUT`，中止；收到布局响应会刷新通信计时和缺失计数 |
| 取料布局收敛 | 需要第13次布局位置修正 | `NOT_CONVERGED`，中止；通用分段对齐同样有12次限制，圆环单次连续跟踪内部不累计该次数 |
| IMU与控制周期 | IMU无效或超过250ms未更新、非转向路线/视觉跟踪航向偏差超过20°、运动控制间隔超过150ms | 路线或跟踪故障，中止；20°不是圆环像素对齐容差 |
| 路线/原地转向 | 当前路线段超过45s；原地转向超过18s | `route_fault`或`turn_timeout`，中止；工位等待不按普通行驶段计时中止 |
| 机构反馈 | 运动准备反馈等待3s；运动下发后超过估算动作时长×2＋3s仍未满足本次目标、到位和新位置反馈条件 | `ERR MECH: feedback timeout` / `AXIS TIMEOUT`，停止并使坐标失效 |
| 驱动和任务状态 | CAN故障、驱动失能/堵转等异常、机构坐标失效、准备或收回姿态不符、动作启动失败 | 停止或任务中止，具体原因见对应故障日志 |
| 操作者/上位机会话 | 停止、急停、会话中断或在线运行超过1000ms无心跳 | 停止；明确启动的离线比赛不依赖上位机心跳 |

以下情况本身不再中止比赛：连续跟踪帧超过350ms未更新时，底盘停车并等待有效新帧后恢复；二层物料达到单轮距离/时间边界后进入稳定与后续轮次，第二轮结束以 `CORRECTION_LIMIT` 继续放置，不代表精确对齐。首次停车识别期间，收到无效目标结果与完全收不到相机响应的处理不同，前者可继续等待目标，后者仍受通信超时约束。
