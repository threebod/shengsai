# 工作区路径回放

在工作区根目录执行：

```powershell
./shengsai/tools/start-route-viewer.ps1
```

脚本使用现有 Python 和 GCC 从当前工作树导出路线，并用默认浏览器打开网页。无须安装依赖、启动服务或连接硬件；生成后也可直接打开 `route_viewer/index.html`。修改路线固件后重新运行脚本刷新快照。导出程序和数据分别保存在被忽略的 `.deps/route-viewer/` 和 `route_viewer/routes-data.js`。

选择启停区、两个障碍区域，以及按比赛顺序排列的起止站点。两轮原料、粗加工和暂存独立列出，可查看相邻工作区或跨多个工作区的连续路线。支持播放、暂停、重播、进度拖动、倍速及点击步骤跳转。

数据直接调用 `presetBuild`、`presetActiveLeg` 和 `arcBlendShape`，覆盖两个启停区与全部105种双障碍组合。完整比赛规划失败时禁用回放，不以直连线代替路线。地图按固件名义坐标绘制300mm车体及缓变曲率圆弧，步骤显示裁切圆弧后的实际直线指令，保留前进、倒车、横移和原地转向的区分。进站调校终点可能偏离名义站点，图中未模拟这项物理偏移、视觉微调、机构取放或真实运动耗时。不能将回放作为实际净空或运动精度验收。

固定候选路线及优先级见 [路线说明](../docs/fixed-routes.md)。出发、扫码和站间路段依次尝试各自三条候选；仅最终返回启停区仍使用原有搜索。源码摘要包含 `firmware/route_candidates.h`，修改候选表后须重新导出。

圆弧步骤区分常规、四点版与7/13实验弯：四点版检查边界及所选障碍，不检查固定区；7/13实验左上弯按当前固件跳过车体扫掠检查，页面会明确标记，不将生成路线等同于通过整车净空检查。

网页显示生成时间和源码摘要，完整来源及SHA-256位于生成数据的 `sources` 字段。无外部脚本、字体、CDN或联网请求。
