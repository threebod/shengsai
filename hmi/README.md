# 串口屏障碍物选择工程

打开 `obstacle_selector.HMI`。基于用户提供的 `testHMI.HMI` 修改，屏幕型号保留为 TJC4827T143_011，480×272，UTF-8，115200 / 8N1。

## 页面与操作

- 上电进入 `page1`，按场地图的红框选择整个区域。按从上到下、每行从左到右编号 1～15；地图朝向为原料区在上、粗加工区在下、暂存区在左。
- 点击未选区域变绿，再次点击取消。最多选择两个不同区域，必须选满两个才可确认。
- 点击“确认并发送”后等待 STM32 校验。主控收到合法数据才发送 `page page0` 切换任务页；未收到确认时留在选择页，可再次点击确认重试。
- `page0.t0/t1/t2` 保留为任务码、正确抓取数、正确放置数，并改为全局变量，以保留选择页显示期间接收的数据。
- 预览图为离线布局预览，实机显示、触摸和串口仍需验收。

## 屏幕 → STM32

USART6：PC6 为 STM32 TX，PC7 为 STM32 RX；屏幕 TX 接 PC7，RX 接 PC6，双方共地。屏幕供电和串口电平按设备规格接线。

六字节二进制帧：`A5 5A 4F A B SUM`。

- A、B：1～15，且不能相同，发送的是原始数值字节，不是 ASCII。
- SUM：`(0x4F + A + B) & 0xFF`。
- 例如选择 5、12，发出 `A5 5A 4F 05 0C 60`。
- STM32 使用滑动窗口恢复帧，拒绝重复、越界和校验错误；合法位置存入 `tjcObstacleRegions` 位图，区域 n 对应 bit(n−1)。5、12 的位图为 `0x0810`。
- 确认回包：ASCII `page page0`，追加 `FF FF FF`，随后刷新计数。日志输出 `HMI OBSTACLES regions=5 12`。

位置仅保存在 RAM，重启后重新选择。本次完成屏幕选择和主控接收；15 区域位图未接入现有“上/下/左/右”路线参数，不会据此自动改变避障路线。

屏幕脚本使用 `printh`、`prints`、`covx` 和 `page`。以本机官方编辑器附带 `help/help.pdf` 为指令依据；官网入口：[淘晶驰资料中心](http://wiki.tjc1688.com/start/index.html)。可读事件导出见 `screen_events.txt`。

- 官方 USART HMI 1.68.1 编译通过：0 错误、0 警告；选择页运行内存 856/3584 字节，编译输出大小 460284 字节。
- `./tools/build-windows.ps1`：完整 CTest 14/14 通过。新增接收测试覆盖所有 1～15 编号组合，以及重复、越界、校验错误、噪声和断帧恢复；测试在 Release 模式仍启用断言。

- 自动化曾抓到模拟器实际发送的 `A5 5A 4F 05 0C 60`；取消重选流程采用上述用户手动验证结果，不宣称自动化全流程通过。
